# Объектно-ориентированный программный комплекс симуляции и анализа телеметрии автодрома (Java 21)

Данный программный модуль представляет собой реализацию ядра системы контроля и автоматизированной оценки практических экзаменационных заездов на учебном автодроме на языке программирования Java (версия 21 LTS).

## 1. Архитектура и структура пакетов

Проект спроектирован в строгом соответствии с принципами объектно-ориентированного программирования (ООП), парадигмой предметно-ориентированного моделирования (Domain-Driven Design) и шаблонами SOLID:

* `ru.mirea.simulator.model` — сущности предметной области (Entity models):
  * `Student` — курсант автошколы;
  * `Instructor` — экзаменатор / инструктор практического обучения;
  * `Exercise` — контрольное упражнение с опорной осевой линией (`ReferenceNode`) и запретными зонами;
  * `ForbiddenZone`, `ZoneVertex` — запретные зоны автодрома и их полигональные вершины;
  * `DrivingSession` — сеанс контрольного заезда, агрегирующий точки телеметрии;
  * `TelemetryPoint` — точка измерений кинематических параметров (координаты, скорость, угол поворота руля);
  * `SessionViolation` — зафиксированный инцидент/нарушение с привязкой к правилу и координатам;
  * `SessionSummary` — итоговый агрегированный протокол заезда.

* `ru.mirea.simulator.filter` — абстракция и стратегии фильтрации зашумленной телеметрии:
  * `TelemetryFilter` (интерфейс) — контракт фильтрации первичных измерений;
  * `MovingAverageFilter` (реализация 1) — центрированное скользящее среднее по сглаживающему окну $w=3$;
  * `PassThroughFilter` (реализация 2) — сквозной фильтр прямого пропуска без модификации данных.

* `ru.mirea.simulator.rule` — полиморфная система штрафных правил:
  * `PenaltyRule` (абстрактный базовый класс) — инкапсулирует код, балл, описание и полиморфные методы `isViolated(Object)` и `formatDetails(Object)`;
  * `BoundaryViolationRule` — проверка наезда на габаритные конусы и линии разметки (код 1.1, 1.2);
  * `LateralDeviationRule` — статистический контроль стабильности удержания коридора движения (SDLP, код 2.1).

* `ru.mirea.simulator.algorithm` — вычислительные алгоритмы обработки пространственной кинематики:
  * `SdlpCalculator` (Алгоритм 1) — проецирование точек траектории на кусочно-линейную осевую линию упражнения, расчет боковых отклонений $d_i$, среднего смещения и стандартного отклонения SDLP ($O(n \cdot r)$);
  * `BoundaryChecker` (Алгоритм 2) — детектирование попадания автомобиля в пределы запретных многоугольных зон алгоритмом Ray-Casting (метод трассировки луча, $O(n \cdot m \cdot v)$).

* `ru.mirea.simulator.service` — сервисный слой:
  * `SessionEvaluator` — координатор бизнес-логики: выполняет конвейер «фильтрация $\to$ расчет кинематики $\to$ детектирование нарушений $\to$ начисление штрафных баллов $\to$ формирование решения».

* `ru.mirea.simulator.util` — утилитарный слой:
  * `SimpleJsonParser` — легковесный синтаксический анализатор JSON для автономного запуска без внешних тяжеловесных зависимостей.

## 2. Требования к окружению

* **JDK**: Eclipse Adoptium OpenJDK 21 LTS (или совместимая версия Java 11+).
* **Среда разработки**: IntelliJ IDEA Community Edition 2024 / 2026 или терминал командной строки.

---

## 3. Сборка и запуск из командной строки

### Шаг 1. Компиляция исходных кодов

Из каталога `src/java`:
```bash
# Для Linux / macOS:
javac -encoding UTF-8 -d out $(find ru -name "*.java")

# Для Windows PowerShell:
javac -encoding UTF-8 -d out (Get-ChildItem -Path ru -Recurse -Filter *.java).FullName
```

### Шаг 2. Запуск симулятора

```bash
# Windows / Linux:
java -Dfile.encoding=UTF-8 -cp out ru.mirea.simulator.Main test_data.json
```
