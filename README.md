## Тема практики
Разработка симуляторов вождения.

## Структура проекта
- `docs/` — разделы отчёта по этапам практики;
- `python/` — процедурная реализация алгоритмов проверки сценария вождения;
- `java/` — объектно-ориентированная реализация ядра симулятора;
- `db/` — физическая модель данных и скрипты схемы PostgreSQL.
