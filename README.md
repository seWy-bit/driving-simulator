## 1. Назначение программы

Программа реализует автоматизированную обработку телеметрии практического контрольного заезда на учебном автодроме в соответствии с бизнес-процессом КТ1 и логической моделью данных.

### Реализованные автоматизируемые операции и алгоритмы:
1. **Фильтрация координат телеметрии (Алгоритм 1.1)** — устранение аппаратного высокочастотного шума позиционирования методом скользящего окна ($O(n)$).
2. **Расчёт метрики бокового отклонения SDLP (Алгоритм 1.2)** — вычисление среднеквадратического отклонения положения транспортного средства относительно осевой линии коридора упражнения ($O(n)$).
3. **Детектирование нарушений границ упражнений (Алгоритм 2)** — пространственный контроль наезда на запретные зоны и разметку автодрома методом трассировки луча (Ray-Casting Algorithm, Point-in-Polygon) со сложностью $O(n \cdot m)$.
4. **Формирование экзаменационного протокола** — агрегация зафиксированных нарушений, начисление штрафных баллов и принятие решения о допуске.

## 2. Архитектура и соответствие процедурному стилю

Программа спроектирована без использования объектно-ориентированных конструкций:
* Полное отсутствие пользовательских классов (`class`), интерфейсов, декораторов `@dataclass`, структур `NamedTuple` и перечислений `Enum`.
* Все данные представлены базовыми структурами данных Python: словарями (`dict`), списками (`list`) и кортежами (`tuple`).
* Логика организована в виде свободных чистых процедур/функций, принимающих данные через формальные параметры и возвращающих новые значения без использования глобальных изменяемых переменных.

### Структура каталога `src/`:
* `main.py` — координация выполнения заезда, загрузка данных, агрегация баллов и консольный интерфейс.
* `telemetry_math.py` — чистые вычислительные процедуры сглаживания координат и расчёта SDLP.
* `boundary_checker.py` — реализация алгоритма Ray-Casting и проверка полигональных зон автодрома.
* `test_data.json` — эталонный набор данных учебного заезда (сущности «Курсант», «Инструктор», «Упражнение», «Правила ПДД», срез сырой телеметрии).
* `requirements.txt` — зависимости (стандартная библиотека Python, внешние зависимости не требуются).

## 3. Требования к окружению и запуск

* **Интерпретатор:** Python версии 3.13.2 (или 3.10+).
* **Внешние библиотеки:** Не требуются (используются исключительно стандартные модули `math`, `json`, `sys`, `os`).

### Команда запуска:

Запуск с тестовым набором по умолчанию:
```bash
python main.py
```

Запуск с произвольным файлом телеметрии:
```bash
python main.py path/to/telemetry_data.json
```
